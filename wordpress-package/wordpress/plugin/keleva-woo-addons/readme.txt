REST endpoints, product options and Elementor widgets for the Keleva Woo theme.

== Description ==

Keleva Woo Addons adds the merchant dashboard API, quick view, product option groups, restaurant extras and optional Elementor widgets used by the Keleva Woo package.

== Privacy ==

The plugin stores only merchant configuration and an audit log required by the local merchant workflow. It does not transmit personal data to a third-party service by itself.
